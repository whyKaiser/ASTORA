ASTORA's first public source pre-release: an Arabic desktop preview and a tested foundation for a future standalone PS4 library.

**This release is not a PS4 application. There is no ASTORA.pkg yet. Downloads go to the computer.**

Included:

- Arabic RTL UI, searchable catalogs and multiple named sources.
- Real PKG header inspection, useful error codes and source/type/size checks.
- Desktop downloads with pause, conditional resume and SHA-256 verification.
- Three developer-hosted free homebrew examples; no game catalog or package binaries.
- 31 automated checks, including real local HTTP and restart/resume tests.
- A real PS4 Games Installer r34 desktop download, verified against its published SHA-256.

Run with Node.js 22+: `npm start`, then open http://127.0.0.1:4318. No npm install step needed.

بداية ASTORA: واجهة عربية، مصادر متعددة، وفحص وتنزيل يعملان على الكمبيوتر. التشغيل المستقل والتثبيت على PS4 هما المرحلة التالية، ولم يكتملَا بعد.
